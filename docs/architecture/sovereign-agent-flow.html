Sovereign Agent Layer 1-4 Execution Model

rubysmithingV1 - Four-Layer Orchestration Architecture

Execution Flow Overview

Detailed Layer Breakdown

1
Survey - Context-Aware Detection
Ground truth establishment before any action
  • Convention Detection: Scan for .rubocop.yml (RuboCop), standard in Gemfile (StandardRB), or .rubysmith. Fallback to community idioms.
  • Dependency Mapping: Identify non-stdlib gems in the project
  • Architecture Mapping: Detect Zeitwerk vs. classic loading, RSpec vs. Minitest, and primary database/framework choices
2
Resolve - Epistemic Verification
Zero-hallucination API verification via Context7
  • Gem API Verification: Use Integrator.verify(gem_name) via Context7 MCP
  • Goal: Zero-hallucination API calls - if resolution fails, annotate output with [WARNING: Unverified API Syntax]
  • Fallback Chain: RubyGems.org API -> Context7 MCP -> ContextCache (SQLite) -> gem-registry.csv -> DegradedError
3
Dispatch - Strategic Delegation
Intelligent task distribution to specialized agents
  • Parallel Dispatch: For independent sub-tasks that can execute concurrently
  • Sequential Dispatch: For dependent chains where output of one feeds the next
  • Executor Agents: rubysmithing-builder (Generation), rubysmithing-researcher (Research), rubysmithing-auditor (Quality/Repair)
  • Dispatch Strategy: Sovereign determines based on task domain and dependency graph
4
Audit - Quality Gates
Consolidated quality assurance through integrated gates
  • Architectural Review: Invoke rubysmithing-auditor for full SIFT Protocol report (8-section assessment)
  • Do-and-Judge Loop: Sovereign sets rubric -> dispatches Auditor (as Judge) -> evaluates Builder's output -> returns PASS/FAIL verdict with evidence
  • Closing the Loop: If Auditor fails artifact, re-dispatch to Builder for remediation until score passes
  • Mandatory Verification Gates:
    Scaffolding: Builder asked clarifying question Database: Connection test performed
  • Final Checks: Coverage Check -> Consistency Check -> Integrity Check (rubocop, steep, sorbet if configured)

Code Flow Example

# Layer 1: Survey - Context-Aware Detection
context = detect_conventions(request.project_path)
dependencies = map_dependencies(request)
architecture = map_architecture(request)

# Layer 2: Resolve - Epistemic Verification
if dependencies.non_stdlib.any?
  result = Integrator.verify(dependencies)
  case result.status
  when :verified
    verified_signatures = result.gem_info
  when :stale_fallback
    # [WARNING: Stale API Syntax]
    verified_signatures = result.gem_info
  when :not_found
    raise GemNotFoundError, result.suggestions
  end
end

# Layer 3: Dispatch - Strategic Delegation
case request.domain
when :generation
  result = rubysmithing_builder.execute(request, verified_signatures)
when :research
  result = rubysmithing_researcher.execute(request)
when :quality
  result = rubysmithing_auditor.execute(request)
end

# Layer 4: Audit - Quality Gates
verdict = run_sift_protocol(result)
if verdict == :fail
  result = retry_with_feedback(result, verdict.issues)
  verdict = run_sift_protocol(result)
end
return { result: result, verdict: verdict }
