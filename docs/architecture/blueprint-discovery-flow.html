rubysmithingV1 - Blueprint-First Code Generation Pattern

Blueprint-First Architecture

How It Works

  1. Builder receives task: User requests code generation (e.g., "Implement a Circuit Breaker pattern")
  2. Builder MUST query BlueprintSearchTool: Before generating any new architectural component, the Builder queries the Librarian for known-good patterns
  3. BlueprintSearchTool calls BlueprintLibrarian: Searches the database using semantic similarity on pgvector embeddings
  4. BlueprintLibrarian retrieves blueprint: Returns the closest matching pattern with description and code snippet
  5. Builder adapts blueprint: Reads the blueprint, understands its structure and conventions, then adapts it to the current task
  6. Code generation: If no blueprint found, Builder generates idiomatic Ruby following Zeitwerk, frozen_string_literal, and Rubocop conventions

Code Implementation

# lib/rubysmithing/agents/builder.rb
class BlueprintSearchTool < RubyLLM::Tool
  description "Searches the Librarian database for known-good architectural blueprints and code patterns."
  param :query, type: :string

  def execute(query:)
    librarian = Rubysmithing::Discovery::BlueprintLibrarian.new
    results = librarian.search(query, limit: 1)
    
    if results.any?
      blueprint = results.first
      Rubysmithing.logger.info "Builder Agent retrieved blueprint: #{blueprint[:name]}"
      return "Found Blueprint: #{blueprint[:name]}\n\nDescription: #{blueprint[:description]}\n\nCode:\n#{blueprint[:code]}"
    else
      Rubysmithing.logger.info "Builder Agent found no blueprints for query: '#{query}'"
      return "No matching blueprint found. Proceed with standard idiomatic Ruby generation."
    end
  end
end
# lib/rubysmithing/discovery/blueprint_librarian.rb
def search(query, limit: 5)
  query_embedding = generate_embedding(query)
  
  results = db[:blueprints]
    .select(:id, :name, :category, :description, :code)
    .select_append { (Sequel.lit("1 - (embedding <=> ?)", "[#{query_embedding.join(',')}]")).as(:similarity) }
    .order(Sequel.lit("embedding <=> ?", "[#{query_embedding.join(',')}]"))
    .limit(limit)
    .all

  Rubysmithing.logger.info "Found #{results.length} matching blueprints"
  results
end

Blueprint Schema

Blueprints are stored with semantic embeddings for efficient similarity search.

# Database Schema: blueprints table
CREATE TABLE blueprints (
  id SERIAL PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT,
  description TEXT NOT NULL,
  code TEXT NOT NULL,
  embedding vector(384) NOT NULL, -- pgvector embedding for semantic search
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Index for fast cosine similarity search
CREATE INDEX idx_blueprints_embedding ON blueprints USING ivfflat (embedding vector_l2_ops) WITH (lists = 100);
