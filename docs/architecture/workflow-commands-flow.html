rubysmithingV1 - Command Orchestration Patterns

Command Architecture Overview

Command Details

Each command follows a consistent 3-step (or 5-step for /vibe) pattern with specialized agents handling each phase.

/flow

Feature Implementation

Implement a feature end-to-end with gem verification, implementation, and quality gate.

  1. 1
    Gem Context Verification researcher verifies gem APIs via Context7
  2. 2
    Feature Implementation builder generates code with blueprint-first approach
  3. 3
    Implementation Verification auditor runs SIFT protocol quality assessment
# Example usage:
/flow "Implement user authentication with JWT"
/schema

Data Infrastructure

Design and implement AI data infrastructure: PostgreSQL/pgvector, chunking pipelines, embedding strategies.

  1. 1
    Gem Context Verification researcher verifies gem APIs for data infrastructure
  2. 2
    Schema Design & Implementation builder designs migrations, models, pipeline files
  3. 3
    Verification auditor validates design and implementation
# Example usage:
/schema "PostgreSQL schema with pgvector for RAG system"
/translate

Foreign Codebase

Translate code from other languages to idiomatic Ruby with verified API calls.

  1. 1
    Deconstruct Foreign Codebase researcher analyzes source code structure and dependencies
  2. 2
    Verify Gem APIs researcher ensures Ruby equivalents exist and are compatible
  3. 3
    Ruby Implementation builder generates idiomatic Ruby translation
# Example usage:
/translate "Convert this Python FastAPI endpoint to Ruby Sinatra"
/vibe

Project Creation

Full project creation workflow from requirements gathering to first task implementation.

  1. 1
    Tree of Thoughts Exploration researcher explores problem space comprehensively
  2. 2
    User Stories researcher defines user requirements and acceptance criteria
  3. 3
    Prioritized Backlog builder creates structured backlog with priorities
  4. 4
    Project Scaffold builder generates project structure and initial files
  5. 5
    First Task Implementation builder implements highest priority task
# Example usage:
/vibe "Create a Rails-based e-commerce platform with Stripe integration"
/audit

Code Review

Comprehensive SIFT Protocol audit with 8-section assessment and actionable recommendations.

  1. 1
    SIFT Assessment auditor performs comprehensive code analysis
  2. 2
    Evaluation Rubric auditor applies standardized quality metrics
  3. 3
    Rubric Evaluation auditor generates final report with scores and recommendations
# Example usage:
/audit "Review the User model for Rails conventions and security issues"
/diagnose

Root Cause Analysis

Identify and resolve issues through systematic root cause analysis and targeted refactoring.

  1. 1
    Root Cause Analysis researcher traces issue to source using Five Whys
  2. 2
    Targeted Refactor builder applies minimal, focused changes
# Example usage:
/diagnose "Why is the UserRegistrationService timing out under load?"
