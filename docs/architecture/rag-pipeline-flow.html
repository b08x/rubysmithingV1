RAG Pipeline Flow

Retrieval-Augmented Generation for Ruby documentation — Ingest-Store-Retrieve pipeline

Ingestion Stage

  • • Ingester processes Ruby gem documentation
  • • Supports YARD documentation format
  • • Creates Document objects for processing

Segmentation

  • • Segmenter splits documents into clauses
  • • Clause: rag/clause/Clause entity
  • • Maintains semantic coherence in chunks

Embedding + Storage

  • • EmbeddingDimensionLocking for consistency
  • • HNSW index for fast approximate nearest neighbor
  • • GIN index for JSONB metadata
  • • ContentHash idempotency via SHA256
